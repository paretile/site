# Paretile

A one-page site for Paretile.

Static HTML and CSS. No JavaScript. Fonts are self-hosted Inter (SIL Open Font License 1.1). There is no analytics and no third-party tracking.

Brand marks, colors, and voice are in [DESIGN.md](DESIGN.md). The same file lives in the public brand pack at [github.com/paretile/brand](https://github.com/paretile/brand).

## What's here

- `/` — the whole site
- `/404.html` — a short lost page
- `/llms.txt` — a plain-text brief for language models
- `/robots.txt` and `/sitemap.xml`

## Domain

Canonical URLs, Open Graph tags, JSON-LD, and the sitemap currently use the placeholder `https://paretile.example`. Swap that host when a real domain is chosen.

## Local preview

```
python3 -m http.server 8080 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8080/`.
